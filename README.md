# Portfólio | Pâmela Fagundes

Portfólio pessoal de **Pâmela Tábata Fagundes da Silva**, Analista de Testes Sênior com mais de 4 anos de experiência em Qualidade de Software, com atuação em sistemas ERP, CRM para o agronegócio e funcionalidades fiscais.

**Acesse o site:** [https://pamelatf.github.io/meu-portfolio/](https://pamelatf.github.io/meu-portfolio/))

---

## Sobre o projeto

Este site reúne minha trajetória profissional, habilidades e projetos na área de QA. A proposta é apresentar os projetos como **investigações de qualidade**, e não apenas como uma lista de tecnologias. Cada card pode ser expandido para mostrar:

| Campo | O que apresenta |
|---|---|
| Missão | O objetivo do teste |
| Heurística | A técnica aplicada, como VADER ou POISED |
| Cenários | O que foi investigado |
| Evidência | Os artefatos gerados, como relatórios e matrizes |
| Resultado | O que o projeto entregou |

## Seções do site

- **Início:** apresentação e chamada para os projetos
- **Sobre mim:** resumo profissional, formação e interesses
- **Habilidades:** ferramentas e conhecimentos utilizados no dia a dia
- **Projetos:** investigações com filtros por categoria (API, Automação, Performance e IA)
- **Experiência:** linha do tempo profissional e estudos em andamento, incluindo a preparação para a certificação CPA (ANBIMA)
- **Contato:** e-mail, telefone, LinkedIn e GitHub

## Tecnologias

- HTML5 semântico
- CSS3 com variáveis, Grid e Flexbox
- JavaScript puro para os filtros, as investigações e a alternância de tema
- Ilustrações em SVG criadas diretamente no código
- Hospedagem no GitHub Pages

## Funcionalidades

- Layout responsivo para desktop, tablet e mobile
- Filtro de projetos por categoria
- Painéis de investigação expansíveis
- Alternância entre tema escuro e claro
- Navegação acessível por teclado, com foco visível
- Respeito à preferência do sistema por movimento reduzido

## Como executar localmente

1. Clone o repositório:

```bash
git clone https://github.com/pamelatf/pamelatfagundes.git
```

2. Abra a pasta do projeto e dê dois cliques no arquivo `index.html`.

Observação: os ícones das ferramentas e as fontes são carregados pela internet, portanto é necessário estar conectado para visualizar o site completo.
